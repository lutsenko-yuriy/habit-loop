# HAB-253: Research: human-facing findability and navigation for docs/skills

## Notes

### 2026-09-09

**In-repo precedent already exists — but scoped narrowly**

`docs/knowledge/notes/INDEX.md` is exactly the "generated topic map" pattern this ticket
asks about — auto-generated from `bookmarks:` frontmatter via `scripts/notes/index.py` —
but it only covers `docs/knowledge/notes/` (106 files), not `docs/` (146 files) or
`skills/` (47 files). `CLAUDE.md`/`AGENTS.md` also carries a hand-maintained "Documentation"
and "Skills" table (purpose-per-file), but it's manual and lists files only — no
cross-linking, no generation, no drift detection. No CI job or script currently checks or
generates links across `docs/`/`skills/`. Corpus size: 146 docs `.md`, 47 skills `.md`,
106 notes `.md`, ~14k lines total docs+skills.

## Debrief summary
