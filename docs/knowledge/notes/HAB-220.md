### 2026-08-24 — correction to the baseline (WU1's own script caught this)

Building `scripts/docs/context_cost.py` (WU1) surfaced two bugs in the plan's original 10,676w baseline, found by diffing the script's output against this session's own real rendered system prompt:

1. **`@`-includes are not whole-line-only.** `AGENTS.md`'s `Details: @docs/VERSIONING.md` (plain prose, no backticks, not a standalone line) *does* expand — it rendered in full at session start. The original audit's whole-line-only assumption silently missed it, which is why `docs/VERSIONING.md` (3,068w) was absent from a first buggy run of the script.
2. **Recursion is capped at depth 2 from `CLAUDE.md`, not unlimited.** `CLAUDE.md` -> `@AGENTS.md` (hop 1) -> AGENTS.md's own `@`-includes, e.g. `@docs/VERSIONING.md`/`@docs/workflows/FEATURE.md` (hop 2), render in full — but *those* files' own `@`-includes (e.g. `FEATURE.md`'s `@skills/shared/decision-guidelines.md`, at hop 3) do **not** expand; they appear as literal, un-expanded `@path` text in the rendered session. Confirmed by reading this session's own actual system-prompt content, not inferred from documentation.

**Net effect: `skills/shared/decision-guidelines.md` (582w) and `skills/shared/wu-splitting-guidelines.md` (295w) are *not* part of fixed cost today, contrary to the original plan text.** They're currently variable cost only — paid when a skill's own `SKILL.md` pulls them in directly (most skills do). The corrected, script-verified baseline is **9,800 words / ≈13,230 tokens** (was wrongly stated as 10,676w/≈14,400 tok).

This does **not** kill WU3: `docs/VERSIONING.md`'s CI-ops content (~2,168w removable), `TROUBLESHOOT`/`RESEARCH`/`POSTMORTEM` (1,269w, still genuinely hop-2 fixed cost), and `FEATURE.md`'s own Multi-WU appendix text (622w, measured directly — excludes the `wu-splitting-guidelines.md` file it points to, which was never fixed cost to begin with) are all still real, still-fixed, removable content. Recomputed: (2168+1269+622)/9800 ≈ **41%** — the ≥40% Checklist-WU target still clears, but narrowly; if any of WU2/WU3's cuts land smaller than estimated the target should be re-verified with the script rather than assumed.

The Linear plan comment on this ticket still states the original, now-superseded 10,676w figure and the "decision-guidelines.md is fixed cost" claim — flagged as stale there; this note is the corrected source of truth going forward.
