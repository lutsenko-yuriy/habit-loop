# HAB-238: Bug: block-main-writes.sh false-positives on commit messages that mention push/main in prose

### 2026-08-17

**Ticket's literal repro text didn't actually reproduce the bug**

The ticket's exact repro (`-m "fix: switch git push ... rebasing onto origin/main"`)
does not trip the hook's push+main pattern — "main" preceded by `/` (as in
`origin/main`) doesn't match the pattern's `[[:space:]:]` boundary requirement. The
real trigger is "main" as a bare word preceded by space/colon (e.g. `"...rebasing onto
main branch"`). Confirmed live — it even blocked one of the diagnostic Bash calls used
to investigate it, mid-session. Verified from source (the actual grep patterns) rather
than trusting the ticket's paraphrased example, and adjusted the test suite's repro
case accordingly before writing the fix.
