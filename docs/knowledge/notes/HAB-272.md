# HAB-272: Enter Name screen: match app theme (background, illustration)

## Notes

### 2026-09-08

**Fresh installs skip straight to the onboarding carousel, never showing EnterNameScreen**

Fresh installs (even after a full `xcrun simctl erase`) skip straight to the onboarding
carousel instead of showing EnterNameScreen first — reproduced independently by both the
agent (simulator) and the user (their own device). Checked `dashboard_screen.dart`'s
`showEnterName` gate, `SharedPreferencesOnboardingService` (both flags correctly default
`false`), and the `displayNamePersonalizationEnabled` release gate (bypassed to `true` in
debug) — none obviously explain it from reading alone. Not caused by this PR's diff (it
doesn't touch any of those files); needs live debugging on a real device/simulator to pin
down. Blocked a manual visual smoke-test of the new illustration — the 24 widget tests
(4 new) cover the change directly instead, including a background-color screenshot taken
before the gating issue was noticed.
