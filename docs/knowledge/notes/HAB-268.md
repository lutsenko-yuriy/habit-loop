# HAB-268: Add a break/eye-strain reminder alongside the nightly block (ADR-0007)

## Notes

## Debrief summary

### 2026-09-09

**What went well**
- Quick, clear ticket with a well-scoped spec already in place from HAB-251's research; no friction implementing against it.

**What was hard or surprising**
- The review + audit passes together produced 11 comments. 6 of those were genuine combinatorial edge cases in `break_reminder.sh`'s state (toggle on/off × interval valid/malformed × state-file present/missing/corrupt/stale × gap short/long/very-long) — malformed interval config, an empty/corrupt state file misread as epoch-0, a missing trailing `exit 0` on the firing path, a `find -mtime` off-by-one, wall-clock-vs-active-time conflation, and path-traversal via `session_id`. The first draft was written by mirroring `nightly_block.sh`/`alert.sh`'s pattern, which are much flatter (boolean toggle, one time check) and didn't force confronting this script's larger state space up front.

**What to change**
- For script/hook tickets whose behavior branches on more than ~2 independent config/state axes, sketch the combinations as a quick table before writing the Red tests — applying `skills/shared/decision-guidelines.md` #3 as a concrete trigger, not just a general principle to recognize case-by-case. Added to `docs/workflows/FEATURE.md`'s TDD micro-cycle (step 3.1).
