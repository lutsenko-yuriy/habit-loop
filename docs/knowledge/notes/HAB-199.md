## Debrief summary

### 2026-07-28

**What went well**
- The issue was identified relatively quickly once the CI diagnostic was in place.

**What was hard or surprising**
- A lot of guessing was needed before landing on the real root cause. The first fix (scrolling `break-submit-button` into view) looked plausible and even passed once, but the actual bug was a keyboard-inset relayout race in `ensureVisible` — only confirmed after adding targeted diagnostic prints (rect, viewport, scroll offset) and comparing a passing run against a failing one. This repeated a lesson HAB-196 had already learned (validate live with real data instead of another code-reading hypothesis) that hadn't made it into the workflow docs, only into that ticket's own debrief note.
- The fix also had to be generalized: the same race was present at every `enterText → tap(break-submit-button)` call site in the file, not just the one that failed first — a second CI dispatch surfaced a different test failing the identical way.

**What to change**
- Make CI's `scenarios.yml` dispatch a required gate in the PR review loop before merge, not just an optional local `/run-scenarios` run — CI's short-viewport/headless emulator surfaces races that don't reproduce locally. Applied to `docs/FEATURE_WORKFLOW.md` step 10.
- Formalize the "diagnose with real data, not another hypothesis" lesson directly in `docs/TROUBLESHOOT_WORKFLOW.md` so it's an enforced step rather than a debrief note that fades. Applied to step 2 (Investigate).
- Captured the new gotcha class (`ensureVisible` racing a keyboard-inset relayout) in `skills/build/implement/resources/widget-test-gotchas.md`.
- HAB-197 (CI scenario-level filtering, still Backlog) is now validated twice over — this ticket alone burned ~9 full-suite CI dispatches (~90 minutes) chasing one flaky scenario. Worth reprioritizing.
- Filed HAB-200 (Backlog, research) to investigate a "test robot" / Page-Object abstraction for integration scenarios, so screen-specific interaction quirks are fixed once in reusable code instead of rediscovered per test.
