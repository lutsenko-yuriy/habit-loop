# HAB-264: Serialize release.yml on main to prevent build-number races

## Notes

### 2026-09-02

**Race caught live, not from a bug report**

PR #435 (0.60.0) and PR #436 (0.60.1) merged ~20 minutes apart. Investigating a
"did the icon fix actually publish yet" question surfaced that both `release.yml`
runs were still in flight simultaneously — `gh run list`/`gh api .../logs` showed
both `resolve-version` jobs resolved the same build number (192), because the
`version-*` tag isn't written until `version-tag` (after distribution), 20-30+
minutes after `resolve-version` reads the tag max. Confirmed via live log
inspection (`--build-number=192` in both `build-android` logs), not from reading
the workflow YAML alone.
