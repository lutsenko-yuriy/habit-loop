# HAB-263: Todo list: fill in-progress showups amber instead of the outline circle

## Notes

### 2026-09-02

**Nested ternaries reduce readability**

While writing the in-progress icon/color selection logic for the todo-list tile
(`isOnBreak ? a : isInProgress ? b : c`-shaped chains), the nested `? :` chain was
harder to scan than a flat conditional would be. Worth a general CODE_STYLE.md
guideline to prefer switch expressions or an extracted helper function over
stacking ternaries beyond one level.

## Debrief summary

### 2026-09-02

**What went well**
- Quick, tight loop — small tests, small implementation, result visible on the emulator right away.

**What was hard or surprising**
- Nothing.

**What to change**
- Added a `docs/CODE_STYLE.md` "Avoid the ternary operator" section (with worked `if`/`else` / `switch` / extracted-helper examples), generalizing beyond the nested-ternary observation captured mid-session — the ternary operator itself (even unnested) is now treated as a code smell.
